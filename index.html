Treetoy

An easily embeddable, interactive JavaScript binary search tree library featuring step-by-step animations and multiple search strategies.

Features & Algorithms

1. Default (3-Way)

Standard BST search performing less-than, equality, and greater-than tests at every node, explicitly checking leaves for null.

2. Sentinel Search

Attaches sentinel leaves assigned to the search key, eliminating all null checks from the inner traversal loop.

3. Two-Way (Candidate)

Executes only a single strict less-than (<) check per node, tracking candidate equality until a leaf is reached.

Quick Start Usage

import { TreeToy } from 'treetoy';
import 'treetoy/treetoy.css';

// Create an interactive BST widget in any container
const tree = TreeToy.create('#tree-container', {
  initialValues: [8, 4, 12, 2, 6, 10, 14],
  treeType: 'default', // 'default' | 'sentinel' | 'two-way'
  searchKey: 6,
  showControls: true,
  showLog: true,
  logCollapsible: true
});

// Programmatic insertion (enforces unique set membership)
tree.insert(9);

// Trigger a new animated search
tree.search(10, /* autoPlay */ true);
